# Raw Data and Analytical Code for the Meta-analysis of Plant Responses to Grazing from a Functional Trait Perspective

## Overview
This repository contains the raw data and R scripts used in the meta-analysis described in the manuscript:

**"Plant responses to grazing from a functional trait perspective: global evidence"** *(Submitted to Nature Communications)*

## Repository Structure
- `Database.xlsx` — Raw data extracted from literature
- `Grazing_Functional_Traits_Analysis.R` — R scripts for meta-analysis

## Requirements
- R version 4.5.2
- Required R packages: metafor, metadat, tidyverse, dplyr, ggplot2, scales, corrplot, igraph, readxl, DT, mice, rfPermute, patchwork
